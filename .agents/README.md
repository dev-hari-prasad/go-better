# Agent Configuration

This folder contains project-specific guidance for coding agents working on GoBetter.

## Files

- `agents.md`: shared project rules and validation commands.
- `rules/backend.md`: backend architecture, security, and worker conventions.
- `rules/frontend.md`: client architecture and UI conventions.
- `rules/documentation.md`: Mintlify and roadmap documentation conventions.

These files are reference material for agents and contributors. Keep them short, concrete, and aligned with the repository's actual code.
