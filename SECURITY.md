# Security Policy

We take the security of GoBetter seriously. If you discover a vulnerability or potential exploit, please disclose it responsibly.

## Reporting a Vulnerability

**Do not file public GitHub issues, discussions, or pull requests for security flaws.**

Please send a private disclosure email directly to:

📧 **`harii.codess@gmail.com`**

### What to Include
- A brief description of the issue and potential impact
- Affected component or endpoint (e.g., `/webhook`, worker pipeline, BYOK vault)
- Steps or a proof-of-concept (PoC) to reproduce the behavior

We will acknowledge reports within **48 hours** and coordinate a private patch before public disclosure. Thank you for keeping GoBetter and our users safe!
